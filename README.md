# Website Trade Mentorship (React + Vite)

## Jalankan lokal
    npm install
    npm run dev

## Deploy ke GitHub Pages
1. Push folder ini ke repo GitHub (branch `main`).
2. Repo > Settings > Pages > Source: **GitHub Actions**.
3. Setiap push ke `main` akan build dan deploy otomatis.

## Yang perlu kamu ganti
Semua teks, harga, nama mentor, dan nomor WhatsApp ada di bagian atas `src/App.jsx`.
