# QR Studio
QR Code generator (React + Vite + qr-code-styling). Custom dot/eye style, logo, download PNG/JPG/SVG, copy to clipboard, dark/light.

## Jalankan
    npm install
    npm run dev

## Setting donasi
Edit `src/config.js`, lalu taruh gambar QRIS di `public/qris.png`.

## Deploy
Push ke GitHub → vercel.com → Import repo. Framework otomatis terdeteksi (Vite). Klik Deploy.
